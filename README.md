# The Training Log

Portfolio of Anisur Rahman (Shakil), built as a training log: work history as training blocks, metrics as PRs, projects as plates. Live target: arshakil.com.

Next.js 16 App Router, TypeScript, Tailwind 4, static export to `out/`.

```bash
pnpm install
pnpm dev
pnpm typecheck && pnpm lint && pnpm test && pnpm build
pnpm e2e
```

- Edit copy and data in `src/content.ts` and `src/gym.ts`.
- State, commands and deploy steps: `docs/PROGRESS.md`.
- Why things are the way they are: `docs/DECISIONS.md`. What still needs an answer: `docs/OPEN_QUESTIONS.md`.
- Conventions and design rules: `CLAUDE.md`.

# arshakil.com

Portfolio of Anisur Rahman (Shakil), drawn as an engineering drawing set. Present state in ink, future state in red.

Next.js (App Router), TypeScript, Tailwind, fully static. See `CLAUDE.md` for conventions and `docs/` for the plan,
progress, decisions and open questions.

```bash
pnpm install
pnpm dev
pnpm typecheck && pnpm lint && pnpm test && pnpm build
pnpm e2e
```

All copy and data live in `src/content.ts`.

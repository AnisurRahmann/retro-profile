Read CLAUDE.md, docs/PROGRESS.md, docs/DECISIONS.md and docs/volumetric/plan.json first, and follow CLAUDE.md (palette-only hex, gates green before every commit, log decisions in docs/DECISIONS.md).

Context. The owner rejected the noise-sheet clouds (smeared, marble swirls, horizon banding) and the flat puff clouds (clip-art). This project builds photographic, real-time volumetric clouds in an isolated lab page, with the sun, moon and stars genuinely BEHIND the clouds, before anything touches the home page. The work runs in many unattended sessions by two agents (Claude Code, and GLM through the same Claude Code CLI) under a conductor. The conductor reads docs/volumetric/plan.json, prepares a worktree, branch and dev server per task, verifies each task (a commit exists, only the task's `owns` globs changed, gates green) and merges it into feat/volumetric-lab. You write the shared brief and the interfaces every later session codes against, plus scaffolding. Do NOT change the home page sky.

1. Write docs/volumetric/BRIEF.md, the single source of context for every later session. It must contain:
- Why: the rejection above; the target is photographic realism in every state, sun/moon/stars behind the clouds.
- Technique: real-time volumetric clouds per Schneider/Guerrilla "Nubis" and Hillaire's physically based sky and clouds. Implement from the techniques; never copy code from Shadertoy (CC BY-NC-SA by default) or any non-permissive source.
- The lab: route /lab/clouds, dev and test builds only; 404 in production unless NEXT_PUBLIC_SKY_DEBUG=1 (use the module-constant pattern from DECISIONS #120). Full-viewport canvas, no site chrome, a controls panel. URL state, e.g. /lab/clouds?t=11:00&cov=0.38&type=cumulus&wind=15&from=270&tier=high&sunAz=&sunEl=&cloudAtSun=0&debug=
- Renderer spec:
  Noise: generated on the GPU at startup into 3D textures. SHAPE 64³ (128³ on the high tier), RGBA8: R Perlin-Worley, GBA Worley fbm at 3 frequencies. DETAIL 32³, RGB Worley fbm. A 64×64 blue-noise 2D texture. Weather map: 2D 128×128 (R coverage, G type: 0 stratus, 0.5 cumulus, 1 cumulonimbus; B precipitation), generated on the CPU, scrolled with the wind.
  Geometry: camera at ground level; spherical shell (earth radius 6,360 km; base 1.5 km; top 4 km; cumulonimbus to 10 km); vertical FOV 60°, horizon at 82% of the viewport height; march between the shell intersections with blue-noise start jitter; early exit at transmittance < 0.01; steps high 64 / medium 40 / low 24; 6 light-march steps.
  Density: shape remapped by a per-type height gradient (stratus thin and flat; cumulus rounded with a flat base; cumulonimbus tall with an anvil), eroded by detail at the edges, × coverage; detail evolves slowly with time.
  Lighting: Beer–Lambert + powder; dual-lobe Henyey–Greenstein (g 0.8 / −0.2, mix 0.5); ambient from the sky gradient (zenith on tops, horizon on bases); sun colour by elevation; aerial perspective toward the horizon colour by distance.
  Background in the same pass, before the clouds: sky gradient (from src/lib/sky/gradient.ts via uniforms), stars, moon (phase-correct, from the existing astro code), sun (limb darkening, bloom). Clouds composite over them with transmittance.
  Performance: clouds into an RGBA16F target at 0.35 / 0.3 / 0.25 × DPR per tier; 2×2 checkerboard temporal reprojection, α 0.25; re-march ≤ 15 Hz; bilateral upsample; composite every frame. Targets: high ≤ 2.5 ms at 1920×1080 DPR 2; low ≤ 3 ms at 375×812 DPR 3.
- Acceptance states: A = 11:00, cumulus, cov 0.38, wind 15 from 270. B = 16:45, cumulus, cov 0.4, wind 10 from 300, the sun partly behind a cloud edge. C = 13:00, stratus, cov 0.95. Checklist: sunlit tops and darker bases; detailed edges, no smear; clouds shrink toward the horizon with no banding; warm undersides and a silver lining at dusk; the sun hidden where covered, with light bleeding through thin edges; overcast is a continuous textured deck with no visible tiling; mobile equally real.
- Ownership: plan.json `owns` is the source of truth. Never edit another task's files. If you need an interface change, write it under "Requests for M1" in your hand-off instead.
- Workflow (every session is unattended): the conductor prepares your worktree, branch and a dev server at http://localhost:$VOL_PORT. Read BRIEF.md, plan.json and the hand-offs of your dependencies (docs/volumetric/handoffs/<id>.md). Implement only your owned files. Screenshots: `pnpm exec playwright screenshot --viewport-size=W,H "<url>" <file>` against the running server, into .shots/volumetric-lab/. Write your hand-off. Run the CLAUDE.md gates. Commit. Never push, never create branches or worktrees, never start or stop servers.

2. Write src/components/sky/volumetric/types.ts with the interfaces every task codes against:
- NoiseTextures {shape: WebGLTexture; detail: WebGLTexture; blue: WebGLTexture; shapeSize: 64|128} and createNoiseTextures(gl, tier): Promise<NoiseTextures>.
- WeatherMapParams {type, coverage, precipitation, windKmh, windFromDeg, seed, forcedCell?: {u: number; v: number; radius: number}} (forcedCell = a dense cumulus cell, used by the lab's cloudAtSun check) and WeatherMap {texture: WebGLTexture; offset: [number, number]; update(dtSec: number): void; setParams(p: WeatherMapParams): void}.
- LabState (every URL param, typed) with parseLabState(search: string): LabState and serialiseLabState(s: LabState): string.
- CloudUniforms: every uniform name and type used by the march, density, lighting and background shaders.
- QualityTier 'high'|'medium'|'low' and its constants (steps, scales, shape size).
- The renderer hook API: setState(state: LabState), registerDebugView(name: string, draw: (gl) => void) for ?debug=<name>, onFrameTime(cb).
- The GLSL module contract: each *.glsl.ts exports a string providing documented functions, at least float cloudDensity(vec3 p, float lod), vec4 marchClouds(vec3 ro, vec3 rd), vec3 background(vec3 rd).

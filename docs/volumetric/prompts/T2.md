Read CLAUDE.md, docs/volumetric/BRIEF.md, docs/volumetric/plan.json and docs/volumetric/handoffs/T0.md first. You own ONLY the files listed for T2 in plan.json.

Implement the weather map typed in types.ts (WeatherMapParams → WeatherMap), replacing T0's placeholder.
1. A pure generator generateWeatherMap(params): Uint8Array (128×128 RGBA): R coverage, G type, B precipitation, A unused. Clouds come in clustered patches, not uniformly: coverage = clamp(lowFreqNoise·1.4 − (1 − coverage)·1.1, 0, 1) with seeded value noise (deterministic per seed). stratus: smooth, near-uniform coverage. cumulus: patchy clusters. cumulonimbus: 1–2 strong cells (gaussian blobs, radius 0.12–0.2 of the map) on top of the patchy field. Precipitation follows the params, concentrated under high-coverage cells. forcedCell (if set): a dense cumulus cell (coverage ≥ 0.95, type 0.5) centred at (u, v) with the given radius, wrapped across the map edges.
2. WebGL wrapper: upload to a 2D texture (LINEAR, REPEAT). update(dtSec) advances offset with the wind (east–west → u, north–south → v; speed proportional to windKmh, with the constant documented). Regenerate only when params change (setParams).
3. Tests in tests/unit/vol-weather-map.test.ts: determinism per seed; measured mean coverage for cumulus at 0.38 within 0.30–0.46, for stratus at 0.95 ≥ 0.9; cells exist for cumulonimbus; forcedCell coverage ≥ 0.95 at its centre; offset direction matches the wind (from 270 → moves toward +u).

## What I built

- `src/lib/sky/volumetric/lab-state.ts`, replacing T0's placeholder: parse/serialise exactly as `types.ts` types
  them, with the validation the brief asks for:
  - ranges clamp: `cov`/`precip` 0–1, `wind` 0–60, `from` 0–359, `sunAz`/`view` 0–359, `sunEl` −90–90, `seed`
    truncated to an integer and clamped to int32;
  - malformed values fall back to the default: dates must be real calendar days (`2026-02-30` is rejected,
    `2024-02-29` accepted), times are strictly `HH:MM` with real clock fields, enums must match;
  - `cloudAtSun` accepts `0`, `1`, `edge` **and `cover`** (M1 F1: the synonym for `1`); serialises back as `0/1/edge`;
  - `presetState("A" | "B" | "C")` = `{...LAB_DEFAULTS, ...LAB_PRESETS[k]}`, i.e. exactly the §7 acceptance URLs.
- The controls panel, `src/app/lab/clouds/controls/`:
  - `index.tsx`: fixed top-right, 264 px, collapsible (button with `aria-expanded`/`aria-controls`), Geist Mono 12 px,
    tokens only (`--ink`/`--surface(-2)`/`--hairline`/`--text`/`--graphite`; the global `:focus-visible` rule gives
    the amber keyboard ring). Sections: presets A–C · time (date field, 5-min slider over the Dhaka day, the real
    sun's elevation + azimuth from `astro.ts` via `labDate`) · clouds (coverage, type, precipitation) · wind (km/h,
    8-point N…NW buttons) · sun (azimuth/elevation sliders that engage the override on drag, "use real sun",
    cloudAtSun off/cover/edge) · render (tier high/medium/low/auto, freeze, seed, camera view + "face sun", debug
    view). Every `LabState` field is covered.
  - `widgets.tsx`: the labelled primitives — `Section`, `Slider` (label + live value + range), `Seg` (one-of button
    group with `aria-pressed`), `Toggle`, `NumField`, `SelectField`, `DateField`, `FrameReadout`.
  - Frame-time readout in the header, visible even collapsed: the mean GPU ms over the last 500 ms of
    `onFrameTime` samples when the renderer reports them (`EXT_disjoint_timer_query_webgl2`), else the mean rAF ms,
    plus the tier. Updated at 2 Hz.
  - Plumbing: each change sets React state at once, then coalesces to **one** `renderer.setState` +
    `history.replaceState(serialiseLabState(next))` per animation frame while a slider drags (T7's note: every
    setState drops the reprojection history).

## Decisions (for M1/T8 to carry into docs/DECISIONS.md)

- The panel **starts collapsed**, remembered in `sessionStorage` (`vol-controls-open`). Reason: `lab:shots` and
  `lab:gpu` screenshot the whole page; an always-open panel would sit in the corner of every T8 review shot. The
  collapsed pill (controls + readout) is ~180×28 px.
- Preset buttons apply `presetState(k)` verbatim — the §7 acceptance URLs — so `debug`, `view` and `tier` reset on a
  preset click. Reviewers comparing debug views across states should set `debug` after the preset, or use URLs.
- `seed` clamps to int32 and truncates; `wind`/`from`/`sunAz`/`sunEl`/`view` stay fractional if the URL gives
  fractions (only the range clamps). The panel itself writes integers.
- The type group abbreviates cumulonimbus as "cb" (standard met abbreviation; the full word doesn't fit 3 columns
  at 12 px). The `title` attribute spells it out.
- The debug select lists `""` + `SHADER_DEBUG_VIEWS` + `"noise"`; an unknown `?debug=` value (a view registered
  later) is added to the select dynamically so the control never shows a blank.
- One-of groups are buttons with `aria-pressed` (Tab visits each, Space/Enter picks) rather than radio inputs:
  they double as toggles for a lab tool and need no arrow-key roving tabindex.

## Known issues

- On software GL (headless Chromium) the readout shows rAF ms at ~180 ms — the renderer really is that slow there;
  on ANGLE Metal it shows GPU ms (verified format only, not the number).
- The date field renders in the browser's locale order (15/12/2026) while the value stays `YYYY-MM-DD`.
- The sun-override sliders show the real sun's rounded az/el while the override is off; engaging the override on
  drag rounds the untouched partner to a whole degree.

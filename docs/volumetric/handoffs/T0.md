## Interface summary (types.ts)

**Tiers:**
- `QualityTier`, with `TIERS[tier]`:

  | Tier | steps | lightSteps | scale | shapeSize | detailSize |
  | --- | --- | --- | --- | --- | --- |
  | high | 64 | 6 | 0.35 | 128 | 32 |
  | medium | 40 | 6 | 0.3 | 64 | 32 |
  | low | 24 | 6 | 0.25 | 64 | 32 |

- `GPU_TARGETS`.

**Geometry:**
- `GEOMETRY`: EARTH_R 6360, CLOUD_BASE 1.5, CLOUD_TOP 4, CB_TOP 10, CAMERA_ALT 0.002, MAX_MARCH 60,
  WEATHER_MAP_KM 40, FOV_Y 60, HORIZON_AT 0.82. They reach GLSL as `VOL_<NAME>` defines.
- `MIN_TRANSMITTANCE`.

**Noise (T1):**
- `NoiseTextures { shape, detail, blue, shapeSize, genMs, dispose }`
- `CreateNoiseTextures(gl, tier) → Promise<NoiseTextures>`

**Weather map (T2):**
- `CloudType`, `CLOUD_TYPE_VALUE`, `WEATHER_MAP_SIZE` (128)
- `WeatherMapParams { type, coverage, precipitation, windKmh, windFromDeg, seed, forcedCell? }`
- `WeatherMap { texture, offset, velocity, update(dt), setParams(p), dispose }`
- `CreateWeatherMap`, `GenerateWeatherMap`

**Lab state (T3):**
- `LabState`: date, t, cov, type, wind, from, precip, tier, sunAz, sunEl, cloudAtSun, freeze, seed, view, debug.
- `ParseLabState`, `SerialiseLabState`, `LAB_DEFAULTS` (state A), `LAB_PRESETS` (A, B, C).

**Scene (T0):**
- `LabScene`: sun, moon, sky, stars, camera, weather (`scene.ts`).

**Uniforms:**
- `CLOUD_UNIFORMS`, 38 uniforms (name → GLSL type).
- `CloudUniforms`: the TypeScript values for the non-samplers.
- `TEXTURE_UNITS`: uShape 0, uDetail 1, uBlue 2, uWeather 3. T7 uses 4 and up.
- `SHADER_DEBUG_VIEWS` → `uDebug`.

**GLSL:**
- `GLSL_MODULES` (order) and `GLSL_CONTRACT` (owner, file and function signatures per module). See BRIEF §6.
- `GLSL_GLOBALS` (gCloudDist).

**Pipeline (T7):**
- `PassContext { gl, tier, width, height, frame, weather, program(key, main), apply(p, overrides), fullscreen() }`
- `CloudPipeline { render, resize, dispose }`, `CreatePipeline`

**Tiers (T7):**
- `ResolveTier`, `TierGovernor`, `CreateTierGovernor`

**Hooks:**
- `VolRenderer { gl, tier, setState, registerDebugView, onFrameTime, dispose }`
- `FrameTime { gpuMs, cpuMs, rafMs, tier }`
- `DebugView { draw(ctx), mount?(host) }`, `DebugContext`
- `VolDebug` (`window.__vol`)

## Known issues

- **The gradient bands** (8-bit steps) on large screens. T5 dithers it with `blueNoise`.
- **In dev, React StrictMode starts the renderer twice.** The first instance is disposed, but the log shows two
  "[vol] tier" lines and two noise timings.
- **The placeholder pipeline marches at full resolution.** That is fine for stubs. T7 replaces it.
- **The camera faces the sun by default**, so a summer noon sun (elevation > 50°) is above the frame. Use
  `view=<az>` to look elsewhere.
- **No in-shader debug views yet.** `uDebug` is set from `?debug=weather|density|transmittance|light|depth`; T4
  implements them.

## Notes for the next task

- **Everyone:** helpers in a GLSL module must start with the module's name, and the assembly test fails otherwise.
  Don't declare `CLOUD_UNIFORMS` in a module.
- **T4:** the placeholder `weatherAt` and `heightFraction` already follow the conventions. The real map is uniform
  coverage until T2 lands, so use `VOL_TEMP_NOISE` for the shape and the coverage pattern.
- **T5:** `uMoonPhase`, `uMoonFraction` and `uMoonAngle` are suncalc's values. `uStarSeed` is the day of the year.
  `uStarWarm` and `uStarCool` come from the palette.
- **T7:** the single-pass main in `targets.ts` shows the composite formula to keep. `EXT_color_buffer_float` is
  already enabled by the renderer.

# Icons

- `github.svg`, `x-twitter.svg`, `linkedin.svg` — brand marks, lifted from the retro-profile source. `currentColor` fills.
- `arrow-up-right.svg` — generic external-link arrow, Heroicons-outline style (2px stroke).

**Heroicons** (primary icon set) is loaded from CDN when needed:
`https://unpkg.com/heroicons@2.1.5/24/outline/<name>.svg`
Used icons in the portfolio: `arrow-up-right`, `chevron-double-down`, `calendar`, `clipboard`, `check`.

No emoji. Unicode glyphs (→ ↗ ↑) are used as lightweight arrow icons inline.
